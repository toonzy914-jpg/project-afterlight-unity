# PROJECT AFTERLIGHT — Unity 6 / URP

**هذه نسخة أولية قابلة للتوسعة (Vertical Slice)، وليست لعبة AAA مكتملة بعد.** المشروع يستخدم مدينة منخفضة التفاصيل تُنشأ بالكود ولا يحتاج نماذج أو صوراً خارجية.

## ماذا يوجد في هذه النسخة؟

- مشروع Unity 6 مع حزمة Universal Render Pipeline (URP).
- منطقة مدينة أصلية مولّدة إجرائياً، فيها شوارع وتقاطعات ومبانٍ ولوحات مضيئة.
- شخصية من منظور ثالث، كاميرا متابعة قابلة للدوران، قفز وركض.
- سيارة قابلة للقيادة، ودخول وخروج بالزر `E`.
- ثلاث سيارات مرور بسيطة، ومطاردة شرطة أولية عند سرقة السيارة.
- مهمة قصيرة: الوصول إلى علامة ECHO GARAGE والتفاعل لاسترجاع قرص البيانات.
- اقتصاد بسيط ومكافأة $500، وحفظ JSON محلي للتقدم والمال.
- تعليمات تحكم على الشاشة ودعم أولي للمس.

## فتح المشروع

1. ثبّت Unity Hub، ثم محرّك **Unity 6** مع خيار **Android Build Support** (Android SDK & NDK Tools وOpenJDK).
2. فك ضغط ملف المشروع إلى مجلد عادي على الكمبيوتر. لا تفتح ملف ZIP مباشرة.
3. من Unity Hub اختر **Add / Add project from disk** وحدد مجلد `ProjectAfterlight_Unity6`.
4. اسمح لـ Unity Package Manager بتنزيل URP والحزم المطلوبة. اتصال الإنترنت مطلوب في أول فتح.
5. عند اكتمال الاستيراد، ينشئ السكربت `AfterlightProjectSetup` مشهد الاختبار ويضبط URP تلقائياً. إذا لم يحدث ذلك، استخدم القائمة **PROJECT AFTERLIGHT → Setup Demo Scene + URP**.
6. افتح `Assets/ProjectAfterlight/Scenes/Afterlight_Demo.unity` واضغط **Play**.

## التحكم على الكمبيوتر

- `W A S D`: الحركة / التوجيه أثناء القيادة.
- `Shift`: ركض.
- `Space`: قفز على القدمين، وكبح أولي أثناء القيادة.
- زر الفأرة الأيمن مع تحريك الفأرة: تدوير الكاميرا.
- `E`: التفاعل مع علامة المهمة أو دخول السيارة/الخروج منها.

## التحكم على الهاتف

واجهة الشاشة تعرض مناطق تحكم تقريبية للحركة والقفز والتفاعل. اسحب جهة اليمين لتدوير الكاميرا، واستخدم العصا الافتراضية جهة اليسار للحركة. هذه واجهة prototype؛ مواضع الأزرار وإمكانية إعادة ترتيبها تحتاجان مرحلة UX لاحقة.

## إنشاء APK للأندرويد

1. في Unity افتح **File → Build Profiles** (قد تظهر **Build Settings** في بعض إصدارات Unity 6).
2. اختر **Android** ثم **Switch Platform**.
3. في Player Settings عيّن Package Name مثل `com.afterlight.project`، واختر Minimum API Level مناسباً لأجهزتك.
4. تأكد من تثبيت Android Build Support وSDK/NDK/OpenJDK عبر Unity Hub.
5. أضف المشهد `Afterlight_Demo` إلى قائمة Scenes In Build إذا لم يضفه الإعداد التلقائي.
6. تستطيع البناء بالطريقة المعتادة من Build Profiles، أو استخدام القائمة **PROJECT AFTERLIGHT → Build Android APK**؛ إذا كانت المنصة الحالية ليست Android، بدّلها ثم شغّل الأمر مرة ثانية. سيُحفظ الناتج في `Builds/Android/ProjectAfterlight.apk`.

لم يُنشأ APK هنا لأن بيئة التنفيذ الحالية لا تحتوي Unity Editor أو Android SDK/ADB. لذلك يلزم تنفيذ الخطوات السابقة على جهازك لإنتاج ملف تثبيت حقيقي.

## الحفظ

يكتب الحفظ إلى `Application.persistentDataPath/afterlight_save.json`. على أندرويد يكون هذا المسار داخل بيانات التطبيق، وعلى الكمبيوتر ضمن مسار بيانات Unity الخاص بالتطبيق. عند تلف الملف تحاول اللعبة الاحتفاظ بنسخة `.corrupt` والبدء بقيم افتراضية.

## حدود النسخة الحالية

النماذج والأصوات مؤقتة ومولّدة من Primitive meshes؛ لا يوجد قتال أو أسلحة أو حركة تسلق/سباحة، والمطاردة والمرور مبسطان، والسيارة ليست نموذجاً فيزيائياً متعدد العجلات. لم أتمكن من تنفيذ Compile أو Play Mode أو APK من هذه البيئة لعدم توفر المحرك. افحص Console بعد فتح المشروع، ثم اختبر على جهاز Android متوسط قبل تقييم الأداء.
